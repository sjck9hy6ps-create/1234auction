사용자 원칙: 거래건수가 부족해 불가피한 경우가 아니면 모든 계산값은 해당 단지·해당 법정동 기준이어야 함.

**Why:** 추천가·예상낙찰가의 근거가 전국 단위인지 물었고, 지역 실제 사례를 우선 쓰길 원함.

**How to apply:** 새 통계/보정을 만들 때 단지→법정동→시군구→전국 순으로 표본 충분(보통 n≥15)한 가장 좁은 범위를 쓰고, 화면에 어떤 범위를 썼는지 표시. 
2026-10-09 적용: 낙찰가 모델에 dong 요인(k=40, 백테스트 오차 5.23→5.15%, 낙찰확률 폭은 지역별로 나눠도 개선 없음), 마진율 비교(marginBandFor)는 동→시군구→전국. 예상매도가는 원래 단지·평형 기준. 관련: [[winbid-model]]
