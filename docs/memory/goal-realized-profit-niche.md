User (2026-10-04): "경매의 핵심은 낙찰될만한 가격이 아니라, 낙찰·매도 후 수익을 구현할 수 있는지." Bid amounts must be profit-realizing, not win-oriented. Regions must be judged separately.
More important than picking obviously popular items is the **틈새시장** — "인기 1등 지역 매물은 누구나 1등으로 판단해 수익성이 떨어진다."

**Niche definition (user, 2026-10-04, corrected me):** 틈새 = 거래가 가능한(매도 가능한) 지역인데 사람들 시선이 안 가는 곳. 유찰 횟수는 틈새와 무관 — 유찰이 많을수록 경쟁자는 오히려 는다. User's bidder model: 신건 = 인기단지면 들어감; 1회 유찰 = 대부분의 경쟁자 참여; 2회+ = 초보자들이 더 몰림. So "2회 유찰 = 틈새" is wrong framing.

**Why:** competition erodes margins on obvious picks.
**How to apply:** measure attention as bidders relative to same-region same-fail-stage norm (control for 유찰), combine with tradability (complex/dong trade volume); look for location-level (동/단지) persistently low attention + enough trades. Judge by realized net profit. Related: [[app-purpose-sale-price]], [[bidding-targets]], [[court-reduction-rules]].

Overall the simple estimate loses money at 1천 target (median −484만, 58% loss), so estimate bias dominates. 🧭틈새 flag was deployed before this result; user decision pending on whether to add margin/warn or drop it.
