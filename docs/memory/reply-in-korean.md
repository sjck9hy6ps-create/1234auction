Always write replies to the user in Korean, including progress updates and summaries.

**Why:** on 2026-10-04 an English reply slipped through, and the user said "앞으로는 전부 한글로 답을 줘". They had asked earlier too ("한글로 말해줘").

**How to apply:** every user-facing message goes in Korean with plain words. Code comments can stay as they are.
