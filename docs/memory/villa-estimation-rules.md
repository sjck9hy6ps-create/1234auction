사용자 요구(2026-10-10): 빌라는 수도권 한정, 예측 신뢰도가 아파트보다 낮으니 마진폭을 키울 것(최소 2,000만원), 구축일수록 마진 커져야, 평형대·연식·승강기가 가격 핵심, 10년 내 건물이 가장 거래 활발.

예상매도가(villaSaleEst, index.html): 같은 건물(24개월·±6㎡)→같은 동(12개월·±8㎡·준공±5년)→시군구, ㎡당 중앙값(최근·비슷한 면적 가중). 백테스트(수도권 빌라 39,959건, 30일 전 자료): 보통 오차 12.5%, ±10% 42%; 건물3+ 6.8~8%, 동5+ 14.6%, 시군구 33%. 시점 보정·층 보정은 효과 없어 미적용.
요인 실측(같은 동·분기 대비 ㎡당): 연식 10년내 +23% / 21년+ −10~−12%; 평형 40㎡↓ +9%, 85㎡↑ −19%; 지하 −38%, 1층 −6%, 5층+ +16%; 승강기(4층+ 건물) 있음 +24% vs 없음 −7%(차이 약 +33%, 층이 높을수록 커짐). 세대당 연 거래율 10년내 10.8% vs 21년+ 8.8%. 오차: 10년내 9.7% / 11~20 11.0 / 21~30 13.6 / 31+ 17.3; 승강기 있음 9.6%, 없음 13.5%.
마진 규칙(villaMarginPlan): 필요 순이익 = max(2,000만, 예상매도가×여유%), 여유% = 연식×근거단계 p90의 절반(최대 25%), 승강기 있음×0.7/없음×1.15. 입찰 상한 = solveAuctionBidFromRecord. 빌라 탭에 표시.
미구현: 비교 거래(동 단위)의 승강기·연식 보정(비교 건물 승강기 정보가 클라이언트에 없음), 빌라 낙찰가 모델.
