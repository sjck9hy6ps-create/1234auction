기준선(수도권 빌라 15,000건 백테스트): 보통 오차 12.6%, ±10% 41.8%; 같은 건물 거래 3건+ 6.6~7%.
- 반경 방식(backtest-villa-radius.py): 300m 15.4%, 500m 16.7%, 1km 18.5%, 커널 가중 13.4% → 기존보다 나쁨, 하이브리드도 15.5%. 사용자 가설(반경이 중요)은 정확도로는 못 확인 → 미적용. 반경은 '환금성(주변 비슷한 금액대 거래 수)' 참고용으로 쓰자고 제안함.
- 전세가 방식(backtest-villa-jeonse.py): 전세만 19.5%, 혼합 30% 14.0%/50% 15.3% → 기존이 최선. 한계: villa_rent 순수 전세가 2025-01~2026-05(약 10.8만 건)뿐이라 건물 단위 전세 5.5%뿐 → 전세 이력 더 쌓이면 재시험 가치. 전세가율 상한(하방 점검)은 미시험.
- 감정가: 감정시점이 제각각이라 보정 어렵다는 사용자 의견. 공시가격은 사용자가 개발호재 신호로 봄(직접 시세 기준 아님).
- 남은 후보: 건축물대장(승강기·연식·층) 기반 한 번에 계산하는 모델(10/13 수집 후), 빌라 호가 입력.
- 대장아파트 기준 비교(analyze-leader-criteria.py): 인기·거래량·평단가·시세 선행 모두 '대장 상승→나머지 초과상승' 상관 0.03~0.11로 거의 없음, 방식 간 차이 없음 → 기준 변경 근거 없음(지방 인기순 유지).
관련: [[villa-estimation-rules]], [[space-rental-villa-plan]]
- 2026-10-10 건축물대장 보정 모델(backtest-villa-hedonic.py, 학습 2023~24·시험 2025~, 대장 연결 51~60%): 보통 오차 12.7→12.3%, ±20% 67.5→69.3%, 상위 10% 과대추정 +33→+27.5% (근거 약한 단계에서 개선). 중요 변수 층>연식>기존추정, 승강기 영향 작음(연결률 낮음) → 앱 미적용, 대장 수집 끝난 뒤 재시험.
- 빌라 전월세 수집기(scripts/collect-villa-rent.mjs, 워크플로 collect-villa-rent.yml, 국토부 RHRent 프록시 endpoint=rhRent): 2025년 20.3만 건 성공 → 2026·2024~2021 순서로 수집 시작(매주 수요일 올해분 자동). 끝나면 건물 단위 전세 시험(backtest-villa-jeonse.py) 재실행.
- 빌라 호가 붙여넣기(parseVillaListings/villaListingCap, 건물 상세 패널): 비슷한 면적(±8㎡)·층 매물 3건+ 하위25% 또는 싼 2건 평균 −3%를 예상매도가 상한으로(아파트와 동일 규칙).
- 아파트 소수입찰(≤3명 46%, 단독 24%) 분석: 신건·유찰 4회+(최저가율 40%↓)·1억↓·40㎡↓·저층·경남/전라/부산 영도 등에서 많고, 소수입찰이 4명+보다 되판 비율 낮음(52% vs 62%, 단독 50%) → '인기 없음 = 환금성 낮음' 경향.
