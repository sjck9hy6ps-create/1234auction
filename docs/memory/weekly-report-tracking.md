사용자 핵심 요구: "과거 모든 입찰추천가와 실제 낙찰가를 비교한 뒤 조정"이 주간 리포트에서 가장 중요. 매일 확인 + 알림 확인 후에도 계속 볼 수 있는 누적 목록 원함.

사실: 입찰후보 예측 저장(predSnap)은 2026-10-08부터(193건, 아파트, 입찰 21일 전부터). 2026-10-09 변경: predHist(날짜별 누적, 최대 25) 추가, 주간 분석이 낙찰일 이전 마지막 저장본으로 비교.
버그 정정: 사건번호는 법원마다 따로라 (사건번호, 시군구)로 매칭해야 함(장유경동리인하이스트 ↔ 군산 소룡동제이파크가 2025-577로 잘못 매칭돼 "예상 낙찰가 오차 -60%"로 보였음 - 모델은 맞았음).
추가: scorecard(추천가 낙찰률·낙찰가÷추천가·낙찰가능성 구간별 예측vs실제, 표본30건+이고 15%p↑ 어긋나면 조정 필요), signal|__weekly_history__ + signal|__weekly_report__|YYYYMMDD(지난 리포트), 상단 📊 리포트 버튼(탭: 이번 리포트/성적표/지난 리포트).
미결: "앱 시세계산 30일 전 → 100일 전" 요청의 의도 확인 필요(winbidBaseEst ref=입찰일-30일, analyze-bidcases as-of 30일; 문자 그대로 바꾸면 최근 3개월 거래가 시세에서 빠짐). 자동 조정(표본 100건 후)은 미구현. 관련: [[winbid-model]]
