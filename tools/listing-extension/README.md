# 호가·탱크옥션 상세 보내기 (크롬 확장)

네이버 부동산 단지 페이지를 열어 둔 상태에서 **버튼 한 번**으로 그 단지의 매매 매물 목록을 경매 앱에 보냅니다. 복사·붙여넣기가 필요 없고, 앱이 단지 이름·평형으로 알아서 임장 후보 물건에 저장합니다.

## 설치 (한 번만)
1. 크롬 주소창에 `chrome://extensions` → 오른쪽 위 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 폴더(`tools/listing-extension`) 선택

## 사용
1. 앱의 `📋 호가 모으기`에서 오늘 볼 단지를 확인 → `네이버 열기`로 단지 페이지 열기
2. 단지 페이지 오른쪽 아래 **📤 호가 보내기** 클릭 (목록 끝까지 내려 읽고 보냅니다)
3. 앱을 다른 탭에 열어 두면 **새로고침 없이 바로 반영**되고, 버튼에 `✅ 앱에 반영됨: 단지 평형 매물 N건`이 뜹니다. 앱 탭이 없으면 `⏳ 앱 탭이 안 열려 있어요`가 뜨고, 앱을 여는 순간 반영됩니다.

## 버전 0.2
- 보낸 뒤 앱이 반영한 결과를 버튼에 보여 줍니다(최대 약 1분 기다림).
- 확장 프로그램을 업데이트했으면 `chrome://extensions`에서 이 확장의 **새로고침(↻)** 을 누르고 네이버·앱 탭을 새로고침하세요.

## 참고
- 사용자가 연 페이지에서 버튼을 눌렀을 때만 동작합니다. 페이지를 자동으로 돌아다니지 않습니다.
- 네이버 화면 구조는 제가 직접 열어 볼 수 없어서(도구 제한) 아직 시험하지 못했습니다. "매매 매물을 못 찾았어요"가 뜨면 목록 탭이 '매매'로 열려 있는지 확인하고, 계속 안 되면 그 페이지의 목록 텍스트(복사한 것)를 알려 주세요.

## 버전 0.3 - 탱크옥션 상세 보내기
- 탱크옥션 **물건 상세 페이지**(사건번호 "경매 ○○○○타경○○○"와 임차인 현황·건물등기가 보이는 화면)를 열면 오른쪽 아래에 **📤 탱크옥션 상세 보내기** 버튼이 뜹니다. 누르면 그 페이지의 글을 앱에 보내고, 앱이 사건번호로 입찰후보 물건을 찾아 **권리분석(임차인·등기·말소기준일)** 을 채웁니다. 붙여넣기가 필요 없습니다.
- 앱은 미납 관리비와 단지 세대수(비어 있을 때만)도 같이 채웁니다.
- 입찰후보에 없는 사건이거나 같은 사건번호가 여러 건이면 반영하지 않고 이유를 버튼에 보여 줍니다.
- 로그인은 직접 하세요. 확장은 로그인 정보를 읽거나 입력하지 않고, 자동으로 다른 페이지로 이동하지 않습니다(한 번에 한 건, 누를 때만).
- 업데이트: `chrome://extensions`에서 이 확장의 새로고침(↻) 후 탱크옥션·앱 탭을 새로고침하세요.
